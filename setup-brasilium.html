Compile e rode
sem dúvida.

Brasilium é uma modificação do empacotamento Linux do Helium. Este repositório compila o navegador; não é um instalador pronto. O build exige Docker e bastante espaço em disco.

Linux

  1. Instale Git, Docker e o plugin Docker Compose pela documentação da sua distribuição.
  2. Garanta Docker ativo: sudo systemctl enable --now docker.
  3. Clone o repositório e entre na pasta.
git clone https://github.com/lucaspwalter/helium-performance.git
cd helium-performance
./scripts/docker-build.sh --performance

Windows 10/11

  1. Instale Docker Desktop com backend WSL 2.
  2. Instale Ubuntu pelo WSL e abra o terminal Ubuntu.
  3. Execute os mesmos comandos Linux dentro do WSL.
git clone https://github.com/lucaspwalter/helium-performance.git
cd helium-performance
./scripts/docker-build.sh --performance

O que esperar

O build completo precisa de aproximadamente 100 GB livres, conexão estável e tempo de compilação variável. Não feche o Docker durante o processo.

Artefatos

Quando terminar, procure o AppImage/binário no diretório de saída indicado pelo script:

find . -type f \( -name '*.AppImage' -o -name 'helium' \) -print

Se o script falhar, copie a primeira mensagem de erro completa. Não tente executar o navegador antes do build terminar.
