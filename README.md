# Lucas Pereira Walter — Portfólio

Portfólio responsivo com projetos de desenvolvimento de software e habilidades técnicas.

## Visão geral

Apresenta projetos, tecnologias, repositórios GitHub, demonstrações comerciais e instruções locais.

## Características

- Filtros por tecnologia.
- Links para repositórios e guias de configuração.
- Galeria de demonstrações responsivas.
- Perfil profissional e habilidades.

## Pilha de tecnologia

HTML5, CSS3 e JavaScript.

## Começando

```bash
git clone https://github.com/lucaspwalter/portfolio.git
cd portfolio
```

Abra `index.html` em um navegador.
