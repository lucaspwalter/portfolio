#Lucas Pereira Walter - Portfólio

Um portfólio responsivo apresentando meus projetos de desenvolvimento de software e habilidades técnicas.

## Visão geral

Este projeto centraliza, apresenta e organiza meus principais projetos de desenvolvimento em um só lugar.

O sistema é um portfólio pessoal estático com uma introdução profissional, seção de habilidades, lista de projetos, filtros de tecnologia, repositórios GitHub, exemplos de sites de negócios e páginas de suporte com instruções para executar cada projeto localmente.

##Características

- Vitrina de projeto responsivo
- Filtros de projetos baseados em tecnologia
- Links para repositórios de origem
- Guias de configuração locais específicos do projeto
- Galeria de exemplos de sites comerciais com sete projeções de segmentos responsivos
- Imagens de visualizações animadas geradas a partir das páginas de demonstração reais
- Identidades específicas do segmento e imagens originais fotorrealistas de heróis
- Formulário de solicitação de layout que prepara uma mensagem do Gmail com detalhes do visitante
- Transições animadas entre páginas internacionais com suporte de movimento limitado
- Seções de perfil profissional e habilidades

## Pilha de tecnologia

- Front-end
-HTML5
-CSS3
- Javascript banido

##Começando

Nenhuma etapa de construção ou instalação de dependência é necessária. Clone o repositório e abra `index.html` em um navegador:

```bash
git clone https://github.com/lucaspwalter/portfolio.git
portfólio de CDs
```
