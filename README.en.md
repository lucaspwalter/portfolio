# Lucas Pereira Walter — Portfolio

Responsive portfolio presenting software projects and technical skills.

## Overview

Showcases projects, technologies, GitHub repositories, commercial demos and local setup guides.

## Features

- Technology-based project filters.
- Repository and setup links.
- Responsive demo gallery.
- Professional profile and skills.

## Tech Stack

HTML5, CSS3 and JavaScript.

## Getting Started

```bash
git clone https://github.com/lucaspwalter/portfolio.git
cd portfolio
```

Open `index.html` in a browser.
