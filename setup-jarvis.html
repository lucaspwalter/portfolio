JARVIS / Linux local

Como rodar o JARVIS localmente

Assistente de voz para Linux com OpenWakeWord, Faster-Whisper, Piper e classificação opcional pelo Ollama.

1. Pré-requisitos

  • Linux e Python 3.11 ou superior.
  • PipeWire ou PulseAudio.
  • Comandos parec, pactl, pw-play, ffmpeg e wtype.
  • Git, microfone funcional e espaço para os modelos locais.

Confirme os executáveis antes de continuar:

python --version command -v parec pactl pw-play ffmpeg wtype

2. Baixar e preparar o Python

git clone https://github.com/lucaspwalter/jarvis.git cd jarvis python -m venv .venv .venv/bin/pip install -r requirements.txt cp config.example.toml config.toml

config.toml guarda caminhos e ajustes pessoais. Ele é ignorado pelo Git.

3. Adicionar os modelos locais

O repositório não inclui os modelos. Edite config.toml e informe caminhos reais para:

  • OpenWakeWord em models/openwakeword/: hey_jarvis_v0.1.onnx, melspectrogram.onnx e embedding_model.onnx.
  • Piper: arquivo pt_BR-cadu-medium.onnx.
  • Faster-Whisper: snapshots locais dos modelos small e medium, contendo model.bin.

Sem esses arquivos, o programa encerra com erro de modelo ausente.

4. Configurar o áudio

Liste as fontes disponíveis:

pactl list short sources

No config.toml, troque jarvis_source pelo nome exato da fonte usada pelo assistente. normal_source é opcional.

[audio] jarvis_source = "NOME_EXATO_DA_FONTE" normal_source = ""

5. Ativar interpretação opcional com Ollama

Com Ollama instalado, inicie o serviço e baixe o modelo configurado:

ollama serve ollama pull qwen2.5:0.5b

Endpoint padrão: http://127.0.0.1:11434/api/generate. Ollama somente escolhe intenções conhecidas; não recebe acesso direto ao shell.

6. Executar e testar

.venv/bin/python jarvis.py

Diga Jarvis e depois um comando registrado. Para validar o código:

.venv/bin/python -m unittest discover -s tests -q

Modo público

Exige confirmação no terminal antes de ações externas:

JARVIS_PUBLIC_MODE=1 .venv/bin/python jarvis.py

JARVIS_UNSAFE=1 remove essa confirmação para ações registradas. Não use sem entender o risco.

Windows 10/11

O caminho mais confiável é usar WSL 2 com Ubuntu. Instale WSL, Python 3.11, Git e os pacotes de áudio dentro do Ubuntu; execute os mesmos comandos Linux deste guia.

Microfone, PipeWire e atalhos do desktop Linux não funcionam nativamente no PowerShell. Para testar apenas a transcrição, use WSLg e confirme o dispositivo de áudio antes de executar.

wsl --install -d Ubuntu git clone https://github.com/lucaspwalter/jarvis.git cd jarvis python -m venv .venv source .venv/bin/activate
